### 1. タイトルと説明文（`build.js` の生成側で直した。データ・記事本文は変えていない）
- **ツールページ**（`toolTitle()`・`toolDesc()`）：「ツール名＋無料でどこまで＋料金」。中身は `data/tools.json` の `pricing`（値札と同じ無料プランの区切り）と `cheapest` だけから作る。
  - 無料の範囲は、値札のかっこ内から数字を含む短い項目を1つだけそのまま使う（例：Notta「文字起こし120分/月」、Napkin AI「週500AIクレジット」）。言い換えない。
  - 料金は `cheapest` の金額（「/月」「/年」が付くもの）に「〜」（最安から）を付ける。※・別途・従量・限定などの注記がある値は、注記を落とすと誤解になるのでタイトルに入れない（説明文には全文を入れる）。
  - 「未確認」の値はタイトル・説明文に出さない。
  - 説明文：`ツール名の料金と無料枠（確認日に公式サイトで確認）。無料枠：…。最安の有料プラン：…。` のあとに既存の概要。110字までで、文の切れ目で切る。
  - これまで `data/seo_fix.json` の `meta` にあったツールの説明文は、生成した説明文が120字以下になったため使われなくなった（ファイルは残している）。`STO` のツールの2件（`tools/gemini-agent-workspace`・`tools/notebooklm`）も使われなくなった。
- **比較・一覧の記事**（`artTitle()`）：「何件を比較」と「確認した月」を前半に置く（例：`AI議事録ツール7つを比較（2026年10月確認）｜tl;dv・Nottaなど`）。
  - 件数は、タイトル・`STO`・見出し（h1）にある「Nつ／N件」、なければ h1 の「：A・B・C」の並び（「など」がないとき）から数える。数えられない記事（ChatGPT以外のAIチャット比較）は件数を入れない。
  - 確認した月は、記事の冒頭に「最終確認日」として出している `updated`（なければ `date`）の年月。
  - 後半（ツール名の並び）は、全体が40字以内に収まるまで後ろから減らして「など」を付ける。
  - 比較・一覧でない記事のタイトルと、記事の説明文は変えていない。
- **カテゴリ**：`○○のAIツールN件｜無料枠と料金`。説明文は件数・無料プランありの件数・最終確認日・ツール名。
- **トップ**：`AIツール新着便｜AIツール55件の無料枠と料金を日本語で`（件数は自動）。
- 誇大・煽りの言葉（最強・必見・最安値・No.1 など）は使っていない。

### 3. 次の行動への導線
- **ツールページの末尾**（`toolNext()`）
  - 「（ツール名）を比べている記事」：比較・違い・一覧・選び方の記事を先に、最大4件。各行に「比較・違いの記事／更新日」。5件目以降は「ほかに○○が出てくる記事（N本）」の折りたたみ（リンクは残す）。比較記事がないときは見出しを「紹介している記事」にする。
  - 「（ツール名）に似たツール」：最大4件。順は `more.diff` で違いを書いたツール → 同じカテゴリ → 同じ記事で紹介しているツール。各行に理由と「無料プランあり・有料 …」。
  - これまでの「関連ツール」は同じカテゴリから最大5件だった（4件に変わったので、ツールページから同じカテゴリの5件目へのリンクが減ったページがある。カテゴリページからのリンクは残る）。
- **記事の末尾**（`readNext()`）
  - 「この話題のまとめ記事」：`build.js` の `HUBS`（`docs/internal-links.md` のハブと同じ。スライド作成・音声読み上げを足した）。各行に「『議事録・文字起こし』の記事をまとめて比べています」のような理由。
  - 「次に読む記事」：同じツールを扱う記事（「Notta・tl;dvも扱っています」）→ 同じ話題の記事 → 足りなければ最近更新した記事、の順に3件。これまでの「あわせて読みたい記事」（同じツールの数で3件。0件でも並んでいた）を置き換えた。
  - 「次にやること」のボタンは、すべて枠のボタン（`.cta.sec`）にした。広告のボタン（塗り）と見分けるため。ニュースの「くわしい解説記事を読む」も同じ。
- **トップの検索**
  - 0件のとき：「『…』に当てはまるツールは見つかりませんでした」と、短い言葉の例・「条件を消して全N件を見る」ボタン・カテゴリと記事一覧へのリンクを出す。
  - 入力した言葉が記事のタイトルに含まれるときは「記事の中から」に最大5件を出す（記事の題名とURLだけをページに入れた。約4KB）。
  - 全角・半角の違いを同じに扱う（NFKC）。件数表示を `aria-live` にした。入力欄に `autocomplete="off"`・`enterkeyhint="search"`。
