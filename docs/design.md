# デザインの方針（AIツール新着便）

2026-10-31 改訂（3版目）。CSS は `build.js` の `const css` にまとめてある（色・文字・余白は先頭の CSS 変数）。

## 方向性：無料枠の「値札」と、すぐ引ける料金の一覧

読者は「無料でどこまで使えるか、いくらかかるか」を知りたい日本の一般の人で、主な使い方はツール名で料金を調べること。

前の版（生成りの紙＋明朝＋罫線の誌面＋朱と藍）は、クリーム色の地とセリフ見出し・新聞のような細い罫線という、よくある型に当たっていたのでやめた。

- **目立たせるのは1か所だけ：黄色の値札**。無料枠があるツールにだけ、値札の形（左端を切り欠いて穴をあけた札）のラベルを貼る。中身は `data/tools.json` の `pricing` の中の無料プランの区切りをそのまま出す（新しい事実は書かない）。それ以外は白・墨・灰で静かにする。
- **トップは調べるところから**：冒頭は小さめの見出しと検索・カテゴリの絞り込み。そのすぐ下に新着ツールの一覧を置く。飾りの画像はトップから外した（`static/hero-ai-*.webp` は残してある）。
- **一覧は行で読み比べる**：同じ形の角丸カードを並べるのではなく、行（カテゴリ・ツール名・説明｜値札｜追加日・確認日）を上下に並べる。
- **記事は1段組で、行の長さは40字前後**（`--measure:42em`）。左揃え。

## 文字

- ゴシック1書体（Hiragino Sans → Noto Sans JP/CJK → Yu Gothic → Meiryo のシステムフォント）。外部フォント・CDN は使わない。明朝はやめた。
- 本文 16.5px（スマホ 16px）、行間 1.85。見出しは 800 の太字、`palt` は見出しだけ。
- 数字は `tabular-nums`（等幅の数字）。「料金ひと目で」の最安の有料プランは 21px の太字。
- 改行は `line-break:strict`、見出しは `text-wrap:balance` と `word-break:auto-phrase`、段落は `text-wrap:pretty`。

## 動き

読み込み時の演出はしない。ホバー・絞り込みなど操作への反応（色の変化 .12s、ボタンの沈み）だけ。`prefers-reduced-motion: reduce` ではすべて止める。

## HTML で変えたこと（`build.js`）

- ツールの行（`card()`）：`c-main`・`c-tag` で包み、値札を足した。「無料あり」は値札の中に移した（日本語対応のラベルはそのまま）。
- 値札の文字（`tagText()`）：`isFree` が真で、`freeSeg()`（料金欄の無料プランの区切り）が「無料・Free・FREE・フリー」で始まるときだけ出す。それ以外（例：区切りの取り出しが別のプランに当たるもの）は「無料あり」だけにする。
- ツールページの「料金ひと目で」：無料枠の値を値札の形にした（文字は同じ）。
- トップ：並びを「冒頭（見出し・検索・絞り込み）→ 新着AIツール → 何をしたいですか？ → 比較・解説記事 → 海外AIニュース → はじめての方へ」に変え、飾りの画像を外した。
- カテゴリページ：ツールの行を `.list` で包んだ。

文言・リンク・JSON-LD・URL・`functions/_middleware.js`・自動生成の流れ（`data/*` → `node build.js`）は変えていない。足した文字は値札の中身（既存の料金欄の一部）だけ。

## 変更前後の違い（390px・1280px で撮って比べたもの）

- トップ：生成りの紙面＋朱の日付線＋イラスト → 面の色の冒頭に検索と絞り込み、その下にすぐ新着ツールの行。390px で検索欄の位置は上から約 630px → 約 290px、新着ツールの一覧の始まりは約 3960px → 約 510px。
- ツールの一覧（トップ・カテゴリ）：罫線の目録（緑の「無料あり」ラベル）→ 行の一覧＋黄の値札（無料枠の中身つき）。
- ツールページ（Notta・tl;dv）：墨枠の「料金ひと目で」→ 面の色、無料枠は値札、最安の有料プランは大きな太字。
- 記事：紙面のカード（約45字/行・中央寄せ）→ 枠なしの1段組（約40字/行・左揃え）。結論は朱の左罫 → 墨の枠。調べ方・出典は面の色。
- ニュース一覧・/about/：明朝の見出し → ゴシック。カードは行の一覧。

見た目の評価は人の確認が必要。
