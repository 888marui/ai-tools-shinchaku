# デザインの方針（AIツール新着便）

2026-10-31 作成。CSS は `build.js` の `const css` にまとめてある（色・文字・余白は先頭の CSS 変数）。

## 方向性：「料金の台帳」を載せた、編集部の誌面

このサイトで読者がいちばん見たいのは、**料金・無料枠と、それをいつ公式で確かめたか**。そこで、よくある「青いボタンと影つきカードのSaaS風」ではなく、紙の誌面と帳簿のような組版にする。

- **紙とインク**：背景は生成りの紙色、文字は墨。影は使わず、罫線（細い線・太い線・二重線）で区切る。
- **一色だけのしるし（朱）**：見出しの頭の短い線、カテゴリ名、手順の番号、表紙の日付に朱を使う。朱は「ここから欄が始まる」の目印で、飾りには使わない。
- **リンクとボタンは藍**：押せるものは藍に統一する（ボタンの塗り・本文リンク・出典）。
- **料金表は台帳**：表の上を太い罫、下を細い罫で締め、見出し行は黒い帯をやめて罫線で区切る。数字は等幅数字（`tabular-nums`）。
- **見出しは明朝、本文はゴシック**：h1・h2 に明朝（端末にないときはゴシックになる。Android の多くと、この確認に使った Linux の Chromium はゴシック表示）。

## 文字と組版

- 書体はシステムフォントのみ（外部フォント・CDN は使わない）。
  - ゴシック：Hiragino Sans → Noto Sans JP/CJK → Yu Gothic → Meiryo
  - 明朝（h1・h2・ロゴ）：Hiragino Mincho → Yu Mincho → Noto Serif JP/CJK → BIZ UDPMincho
- 本文 16.5px（スマホ 16px）、行間 1.85、字間 .02em。`palt`（詰め）は見出しだけにかけ、本文はベタ組み。
- 改行：`line-break:strict`（行頭の小書き・約物を避ける）、見出しは `text-wrap:balance` と `word-break:auto-phrase`（対応ブラウザで文節で折り返す）、段落は `text-wrap:pretty`。
- 表のセルは `overflow-wrap:break-word`（「NotebookLM」のような語を途中で切らない）。スマホでは見出しつきの表のセルに最小幅を付け、横スクロールにする（「← 横にスクロールできます →」が出る）。

## 状態

- リンク：下線あり。ホバーで下線を太く。訪問済みは紫がかった藍（#4a3a78）。ナビ・カード・ボタンは訪問済みでも色を変えない。
- フォーカス：3px の藍の外枠（`:focus-visible`）。
- `prefers-reduced-motion: reduce` で、すべての transition とボタンの沈みを止める。
- 印刷時はナビ・追従ボタン・LINE の欄を隠す。

## 変えていないもの

記事・ツール・ニュースの本文と事実（料金・機能・出典・確認日）、運営者・プライバシー・広告表記の文言、広告のURLと `rel`、URL構成、`functions/_middleware.js`、JSON-LD、自動生成の流れ（`data/*` → `node build.js`）。
HTMLで変えたのは、ヘッダーの `<nav>` の閉じタグの追加と、トップの「何をしたいですか？」のアイコンの色の指定（インラインの色 → CSS の `currentColor`）だけ。

## 変更前後の違い（390px・1280px で撮影して比べたもの）

- トップ：青のグラデーションの表紙 → 白い紙面＋朱の日付線。掲載数を罫線で挟んで見せる。手順の3枚のカード → 大きな朱の数字の目録。ナビはスマホで2段（約110px）→ ロゴ＋1行の横スクロール。
- 記事：黄色の結論枠 → 生成り＋朱の左罫。「この記事の調べ方」「用語」は同じ灰色の枠 → 調べ方は藍、用語は灰で区別。比較表の黒い見出し帯 → 罫線の台帳。スマホの表は列が細く「Noteboo/kLM」と切れていた → 語を切らず横スクロール。
- ツールページ（Notta・tl;dv）：「料金ひと目で」の緑枠 → 墨枠＋墨地のラベル。スマホでは項目名と値を縦に並べる。
- カテゴリ・記事一覧・ニュース一覧・/about/：同じ部品の置き換え（カードの影をやめて罫線）。
- 横はみ出し・外部リクエストは、変更前も後もなし。

見た目の評価は人の確認が必要。明朝の見出しは、明朝のない端末（Android の多く）ではゴシックで表示される。
